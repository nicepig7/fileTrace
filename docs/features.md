# 📊 분석 결과 및 뷰어 기능

본 문서는 TraceFile 프로젝트의 정적 분석 산출물(SQLite DB)과 대화형 웹 뷰어(Web Viewer)가 제공하는 핵심 기능 명세를 설명합니다.

---

## 📦 분석 결과 아티팩트 (Analysis Artifacts)

Node.js 분석기 실행(`npm run build:data`)이 완료되면 `public/` 폴더에 생성된 SQLite 통합 데이터베이스(`data.sqlite`)가 저장되며, 이후 빌드를 통해 `report/` 폴더 내에 최종 시각화된 웹 리포트가 배포됩니다.

- **`data.sqlite`**: 분석된 API 호출 흐름, 테이블, MCI 매핑 데이터 및 클라이언트(Vue/AOS) 연계 내역 전체를 단일 파일로 담고 있는 프론트엔드 내장형 데이터베이스입니다. 이를 통해 대용량 데이터 조회 시에도 뛰어난 성능과 유연한 쿼리를 제공합니다.

---

## 🌐 대시보드 UI 주요 기능 (Interactive Viewer)

### 1. 도메인별 전용 뷰어
- **API 탐색기 (`/api`)**: End-to-End API 호출 흐름 탐색. Controller부터 DB Mapper까지의 전체 트리 전개 및 클라이언트(Vue/Android) 화면 연계 뱃지 제공.
- **테이블 탐색기 (`/table`)**: DB 테이블별 CRUD 쿼리 및 연관 API 역추적 매핑(BFS 역방향 호출 그래프 기반). 컬럼 상세 속성 및 연관 관계 탭 분리, 컬럼 검색어 하이라이팅, 마스터 리스트 접기/펼치기(Collapse) 지원.
- **MCI 전문 탐색기 (`/mci`)**: 대외계 연계 전문 목록, 사용 인터페이스, 호출 위치 추적 및 연관 API/화면 역방향 매핑, 영문/베트남어 사전 툴팁 연동.

### 2. 공통 사용자 경험 (UX)
- **통합 검색 및 필터**:
  - 프로젝트 필터 (`All`, `MBW`, `ADM`)로 타겟 시스템 즉각 분리.
  - 패키지 사이드바 필터 및 URL, 클래스명, 테이블명, 개발자 ID 통합 검색.
- **인터랙티브 툴팁 및 팝오버 (`TooltipPopover`)**:
  - 트리 내 메서드 호버 시 Git Blame 소유권 정보 표시.
  - 테이블 목록 호버 시 상세 정보 툴팁 노출 (좌/우 방향 스마트 배치).
- **GitLab 소스코드 딥링크**:
  - 각 노드, 클래스, MCI 뱃지 클릭 시 형상관리 시스템(GitLab)의 정확한 라인 번호로 즉시 이동.
- **데이터 내보내기**:
  - API 매핑 리포트, MCI 호출 목록, DB 테이블 목록 및 상세 컬럼 정의서를 Excel(`.xlsx`) 파일로 다운로드.
- **모던 UI 및 테마**:
  - Vanilla SCSS `@layer` 기반의 고성능 디자인 시스템 및 다크 모드 지원.
  - 표준 아이콘 시스템(`BaseIcon`) 및 상태별 피드백(`LoadingBox`, `ErrorBox`, `EmptyBox`).
