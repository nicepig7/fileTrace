# Script Directory

이 폴더는 TraceFile 프로젝트와 연관된 공식 유틸리티 스크립트 및 자동화 도구들을 관리하는 곳입니다.
프로젝트 개발 및 유지보수를 돕는 다양한 스크립트 파일들이 위치합니다.

## 보유 스크립트 목록

* **`pull_all_mbw.bat`**
  * `D:\temp` 하위에 위치한 모든 `mbw-*` 프로젝트 디렉토리를 순회하며 `git pull`을 일괄 수행하는 윈도우 배치 스크립트입니다.
  * 실행 시 콘솔 환경이 UTF-8로 변경되어 한글 및 Git 출력 메시지가 깨지지 않도록 설정되어 있습니다.

* **`extract_java_usage.cjs`**
  * 프로젝트 내 Java 소스 코드의 사용 현황 및 연관 관계를 추출/분석하는 Node.js 유틸리티 스크립트입니다.

> **참고**: 일회성 테스트 목적이거나 임시로 작성된 스크립트들은 `temp/script/` 폴더에서 작업 및 관리한 뒤, 그 효용이 입증되고 프로젝트 공식 도구로 편입될 때 이 폴더로 이동시키는 것을 권장합니다.
